# PROJECT_NAME

A Shopify storefront built with [Liquid Loom](https://github.com/yotamon/Liquid-Loom).

The starter uses Shopify-native component CSS/JavaScript by default and keeps Vite/Tailwind optional.

## Start

```bash
__INSTALL_COMMAND__
__DEV_COMMAND__
```

Use `__BUILD_COMMAND__` for a deployable theme in `dist/theme`, `__EXPLAIN_COMMAND__` for the deterministic project model, `__DOCTOR_COMMAND__` for environment diagnostics, and `__VALIDATE_COMMAND__` before shipping.
